# Canvas Explorer

Проводник для Windows, в котором у каждой папки может быть **холст**: список файлов становится окном
на бесконечном полотне, а вокруг него можно закреплять живые окна предпросмотра файлов — изображения,
текст, Markdown, аудио, видео и PDF. Интерфейс тёмный, компактный, с акцентным цветом из настроек Windows.
Язык интерфейса — русский.

## Возможности

- **Холст для каждой папки** — пан и зум, магнит и привязка краёв, раскладка хранится в скрытом `.canvas.json`.
- **Живые предпросмотры** — редактируемый текст и код (автосохранение в исходной кодировке), Markdown
  («Превью / Код»), изображения, PDF, аудиоплеер с волной, видео.
- **Список и сетка** — выбор для каждой папки, три плотности строк, превью Windows в плитках, выделение рамкой.
- **Вкладки** и история навигации, поиск, адресная строка.
- **Теги** — хранятся в самом файле (поток NTFS `:canvas.tags`) и переезжают вместе с ним.
- **Левая панель** — избранное, диски, теги; может стоять слева или справа.
- **Общие плееры** — звук и видео продолжают играть при смене папки, громкость у каждого файла своя.
- Файловые операции через Shell API: корзина, отмена, системный прогресс.

## Требования

- Windows 10 (19041) или новее
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0): `winget install Microsoft.DotNet.SDK.8`

## Сборка и запуск

```bash
dotnet build src/CanvasExplorer   # Debug
build.cmd                         # Release в dist\
run.cmd [папка]                   # пересобрать и запустить
```

Попробовать можно на готовом примере: `run.cmd samples\Пример`.

## Тесты

```bash
test.cmd        # модульные тесты (секунды)
test.cmd ui     # плюс UI-сценарии на настоящем exe (~4 мин, двигают мышь)
```

## Стек

C# / WPF (.NET 8), весь интерфейс нарисован самостоятельно; Markdig, NAudio, Windows.Data.Pdf;
шрифт Onest встроен.

## Данные

- `%AppData%\CanvasExplorer\` — настройки и индекс тегов.
- `<папка>\.canvas.json` — раскладка холста этой папки.
